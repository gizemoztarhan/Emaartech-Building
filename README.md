# 🏠 Emaartech-Building

This project is a modern website for showing real estate. It has a clean and easy-to-use design, and it works well on all devices thanks to its responsive Bootstrap layout.

---

## ✨ Features

🔹 Mobile-friendly (Responsive) layout  
🔹 Stylish navigation menu  
🔹 Carousel (Slideshow) section  
🔹 Popular residence cards  

---

## 🛠️ Technologies

| 💻 HTML5         | Page structure               |
| 🎨 CSS3          | Styling and appearance       |
| 🅱️ Bootstrap 5   | For responsive design        |
| ⭐ Font Awesome  | For icons                    |
